# Public demo listings

The listings with `is_demo = true` and references `DM3A4B`, `DM3C5D`, and `DM3E6F` are fictional examples for presenting the website: one each in Bodija, Ibadan; Lekki, Lagos; and Maitama, Abuja. Their location pairing, rooms, and other details are illustrative, not actual inventory. They have no price or availability confirmation. Public pages label them as demos, suppress availability and enquiry controls, skip listing structured data, and omit them from the sitemap. Database RPCs reject enquiries and reports for demo references.

The image rows use reserved paths under `demo-assets/`. `lib/data.ts` maps those paths to generic Unsplash stock photos; they are not stored in Supabase Storage and do not depict the sample properties. The site CSP allows the Unsplash image CDN for these demo photos.
